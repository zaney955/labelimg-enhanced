# Keep the left rail dedicated to Canvas tools

The application will use one fixed left-side Canvas tool rail containing only direct Canvas tools: Selection/Edit, Draw Box, Pan, and Crop. Workspace entry, navigation, review state, saving, format choice, image quick transforms, selection commands, annotation visibility, and zoom move to their task-specific command surfaces.

The rail is locked rather than movable, floatable, closable, or mode-dependent. Beginner and advanced variants and automatic-overflow mixed toolbars are rejected because they change routine command locations, consume the Canvas, and hide primary tools at ordinary window sizes. The complete interaction and responsive contract is specified in [Canvas Tool Rail and Command Surfaces](../design/canvas-tool-rail.md).
