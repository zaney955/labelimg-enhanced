# Synchronize only the current annotation document

LabelImg will continuously synchronize Canvas content and editing history only for the active annotation storage resources of the image currently displayed, automatically rebasing a clean document after a stable valid external change and requiring explicit conflict resolution when local edits are dirty. The active annotation directory watcher may also compare lightweight resource metadata and refresh the workspace index, file-list status, and candidate-label contribution only for affected inactive image names; it must not open those documents into the Canvas, rebase their histories, or perform a full workspace scan for each event. Inactive documents are loaded when their images are opened. This replaces the earlier no-watcher rule because users need external edits and copied annotation files to appear while avoiding background history replacement and the scaling and ambiguity costs of continuously reconciling every document.
