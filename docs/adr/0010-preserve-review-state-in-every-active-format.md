# Preserve review state in every active annotation format

Batch review changes and their recovery will preserve each image's selected active annotation target rather than converting the image to Pascal VOC. Pascal VOC keeps its existing root review attribute, YOLO stores one leading `# labelimg-review: verified|questioned|unreviewed` metadata comment, and CreateML stores `verified` and `questioned` fields on each image record. Readers ignore unrelated YOLO comments, and existing CreateML records without explicit review keys retain the legacy interpretation that a non-empty record is verified.

A shared CreateML file is indexed by `(collection path, normalized complete image reference)`. Qualified relative and absolute references retain their path identity, while legacy basename-only references retain basename matching. The workspace rebinds a history-reconstructed document to its unique original record reference before saving. Document choice, candidate-label contribution, unsaved in-memory override, conflict association/counting, review update, and review recovery all operate at that record identity while storage conflicts and physical writes remain collection-wide. One record's unresolved multi-format ambiguity must not suppress unrelated records from the same collection, and zero or multiple matching records fail explicitly.

Forcing all batch review changes into Pascal VOC or treating a shared CreateML path as one indivisible candidate-label source is rejected because both approaches lose the user's active-format intent and conflate independent image documents.
