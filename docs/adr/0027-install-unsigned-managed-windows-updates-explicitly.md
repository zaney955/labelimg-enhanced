# Install unsigned managed Windows updates explicitly

LabelImg Enhanced will publish a Windows 10/11 x64 PyInstaller onedir bundle inside a current-user Inno Setup installer. The installer has a stable AppId, installs beneath LocalAppData without elevation, owns shortcuts and uninstall behavior, preserves user settings and annotation data, and deliberately has no Authenticode signature because the project has no code-signing certificate. The release workflow builds the executable on Windows, generates SHA-256 only after the installer is complete, attests the staged assets, and creates a draft Release for manual publication.

Only an executable carrying the exact adjacent Inno managed-install marker may offer application installation. Source and pip runs continue to expose an explicit wheel command, while portable frozen builds may only open the Release. A managed installation downloads the small checksum manifest before streaming the fixed-name installer into a private temporary directory with a 512 MiB limit, requires one exact SHA-256 entry, and never treats that integrity result as publisher authentication. Download progress remains in the independent update center even when its window is hidden, and failure, cancellation, and installation readiness are explicit states. A verified candidate runs only after the user selects Install Now; the updater never installs silently, forces the workbench closed, or bypasses unsaved-change, conflict, loading, or worker guards.

The accepted rollback boundary is the Inno installation transaction only. Post-launch health probing, last-known-good selection, automatic downgrade, and session restoration are deferred because they require a stable launcher and versioned installation layout. The bundled GPL build includes the GPLv3 text, third-party notices, tagged source, and reproducible packaging inputs while the project's own source retains its MIT grant.
