# 全局界面缩放

[UI 设计规范](ui-guidelines.md)维护通用呈现规则；本文维护应用缩放、画布缩放、快捷键和持久化的边界。

## 两套独立比例

界面缩放控制应用自有的菜单、工具提示、字体、图标、控件、布局间距、侧栏、停靠面板、编辑器、状态栏、对话框及画布内操作浮层。画布缩放继续控制图像与标注几何的显示变换。原图像素、标注坐标、类别颜色、撤销历史及未保存状态均不因界面缩放改变。标注文字和线宽沿用独立的标注显示设置。

窗口边框、系统标题栏和原生文件选择器保留平台缩放。系统 DPI 与应用界面比例是两层独立设置：所有界面尺寸先在逻辑像素中按应用比例计算，Qt 再负责 DPR 映射。跨屏不重写应用保存的比例，不手动再乘 DPR。

默认 100%，档位为 `75 / 80 / 90 / 100 / 110 / 125 / 150 / 175 / 200`。放大、缩小进入相邻档位；上下限停在端点，相应动作禁用。100% 是应用设计基线，继续尊重系统显示缩放。无效旧设置回退为 100%，有效数字归到最近档位。

## 入口与快捷键

视图菜单提供放大界面、缩小界面、恢复界面默认大小，以及显示当前百分比的界面缩放子菜单；画布命令独立分组。外观与首选项复用同一比例控件、同一控制器和同一设置键，不另建状态。首选项可搜索“界面”“缩放”“zoom”“scale”。帮助中的快捷键目录直接读取实际动作。

| 操作 | 快捷键 |
| --- | --- |
| 放大整个界面 | `Ctrl+=`；兼容 `Ctrl++` |
| 缩小整个界面 | `Ctrl+-` |
| 恢复界面 100% | `Ctrl+0` |
| 放大画布 | `Ctrl+Alt+=`；兼容 `Ctrl+Alt++` |
| 缩小画布 | `Ctrl+Alt+-` |
| 画布适应窗口 | `Ctrl+Alt+0` |
| 画布实际大小 | `Ctrl+1` |
| 画布适应宽度 | `Ctrl+Shift+F` |
| 画布光标锚定缩放 | 画布内 `Ctrl+滚轮` |

旧的 `Ctrl+=`、`Ctrl+-`、`Ctrl++`、`Ctrl+0` 画布绑定已迁移，不能保留冲突别名。画布底栏加减、滑块、百分比菜单和原有滚轮行为继续操作画布，底栏百分比只表示图像比例。

底栏右侧的顺序为“画布放大镜 → 画布缩放控件”，画布缩放比例菜单位于最右端。全局比例依旧由视图、外观、首选项及全局快捷键调整，普通“界面缩放”结果文字属于中间临时提示。

全局命令在无图像、列表/文本输入焦点、应用自有对话框及浮动面板中可用。应用事件过滤器仅认领上述全局序列，处理 `ShortcutOverride` 和 `KeyPress`；不吞掉输入法文本及其他修饰组合，不对一个按键重复触发。首次按键立即执行；长按时，同一事件轮次内排队的自动重复按键累计目标档位，只执行一次完整重排和保存，不能丢失档位步数。新的显式比例/恢复操作取消旧的排队请求。操作系统原生窗口的按键路由由平台负责。

## 持久化与反馈

比例立即应用并保存为 `interface/uiScale`，下次启动自动恢复。外观对话框里的比例行明确说明“调整后立即保存”；颜色模式/强调色原有的保存与取消回滚语义不变，取消颜色预览不会撤销独立的界面比例调整。

缩放结果通过应用状态消息显示；比例菜单与已打开的设置控件同步投影。恢复 100% 只恢复比例；恢复默认布局只恢复停靠布局，两者互不代替。重置所有设置继续沿用既有确认和清理流程。

## 布局与画布

调整界面比例保留主窗口外部尺寸。工具栏继续按既有优先级折叠次要入口；停靠位置、页签关系、显隐、列表选择及输入内容保持。停靠面板尺寸按比例请求调整，由 Qt 结合可用空间和最小约束分配。内容空间不足时滚动，面板选择操作区保持在滚动区域外。外观色板在 8/4/2/1 列间重新排列，模式分段在必要时改为纵向，不能裁掉名称。画布视口不足以容纳复核按钮的完整名称时，三个按钮在右上角纵向排列，继续共用原有渐隐色带，不压缩字号或省略名称。

应用对话框的优选尺寸按比例计算并限制在当前屏幕可用区域。共享对话框默认让内容滚动，确认/取消和功能提供的历史操作位于滚动区域外。应用面板使用相同的内容滚动与固定底部操作原则。

裁剪参数条在宽视口保持单行；大比例或窄视口时将坐标/尺寸改为两列参数网格，必要时将比例选择与应用/取消分别换行。所有输入和操作保留在画布视口内，恢复宽视口后自动回到单行，参数值、裁剪区域及拖动定位语义保持。

| 当前画布模式 | 界面缩放后的行为 |
| --- | --- |
| 手动比例 | 保持图像比例，保留原视口中心对应的图像位置；接近边界时服从现有平移约束 |
| 适应窗口 | 保持模式，根据变化后的可用视口重新计算图像比例 |
| 适应宽度 | 保持模式，根据新的可用宽度重新计算图像比例 |

视口重新布局结束后再恢复锚点或重新适应，合并同一轮连续变化。恢复后若滚动条显隐再次改变视口，继续等待稳定并重新定位/适应，再结束事务。界面比例不加入图像变换矩阵，也不写入标注文档。

## 共享实现

- `ui/metrics.py`：不可变基准、档位、`dp()` 整数长度、`sp()` 浮点绘制长度、`scaled_size()`、自绘/命中测试共用的 `Metric` 及 `scale_changed(int)`。QSS 从保留的未缩放模板重新解析；Qt 5 的像素字号使用整数，避免小数字号被忽略后回退到点字号。
- `ui/scaling.py`：应用唯一的 `UiScaleController` 与几何适配器。通过 `QApplication.instance().ui_scale` 或 `window.ui_scale` 获取；`percent`、`set_percent()`、`zoom_in()`、`zoom_out()`、`reset()` 是统一入口。
- 几何适配器保存构造期固定约束、图标尺寸、布局边距、间距和 spacer 的 100% 基准，在既有和新建控件上更新。QSS 自己计算的最小约束保持归样式模板负责，避免重复缩放。主题切换保留旧样式 polish 和配色缓存失效流程；仅缩放时直接替换发生变化的样式，不先清空样式，相同模板及解析结果不重复绑定。
- 基础控件样式归独立区域根所有，工作台完成组装后由 `scope_workbench_styles()` 分配到工具栏、菜单栏、状态栏、画布容器和停靠根。标题/内容及嵌入浮层继承所属区域的基础规则，不逐层复制整套规则；主窗口只保留配色规则，原生停靠分隔尺寸由 `IconStyle` 缩放。比例变化只刷新当前可见区域，不重设 QApplication 样式，也不重算隐藏窗口的 QSS。隐藏编辑器、菜单及无父级临时窗口在 polish/show 前补齐当前比例，并在首次显示时校正原生控件的字体缓存；原生文件对话框继续服从平台。隐藏浮层若在 `show()` 前按 `sizeHint()` 自行布局，先调用 `prepare_surface_scale()`，用最终控件高度进行测量。
- 动态尺寸用字体度量、可用区域和 `dp()` 间距计算，设置 `uiScaleDynamicGeometry` 排除固定约束的重复适配；完全由数据/视口决定的尺寸使用 `uiScaleGeometryExcluded`。Canvas 的图像几何排除适配，但其操作浮层独立接入。
- `ui/scale_control.py` 复用设置行；`workbench/ui_scaling.py` 投影视图菜单、状态反馈和画布重排。Qt 对象拥有信号连接及定时器，窗口销毁后不保留调用已删除控件的闭包。应用级控制器弱引用 QApplication 和窗口动作；启动入口在主窗口关闭时释放原生控件，避免把样式资源的销毁留到解释器退出。
- `IconStyle` 只调整归原生样式负责的度量，不再次放大已缩放的内容、字体或图标。SVG 按目标逻辑尺寸和实际 DPR 绘制。

所有缩放从不可变基准重算，不反复乘当前控件尺寸。整数取整只在布局边界执行，恢复 100% 不累积尺寸误差。构造期基础常量由统一适配器负责；动态布局、自绘与命中区域使用同一个度量来源。

## 验证

`tests/workbench/test_ui_scaling.py` 覆盖真实快捷键、长按重复合并及步数、全局/画布隔离、模态输入焦点、既有/新建/隐藏/无父级窗口、保存恢复、端点、反复缩放、主题/语言和适应模式。回归检查缩放不重设应用、主窗口及隐藏编辑器样式，相同样式不重新绑定。缩放事务独立抑制视口重排并清除旧锚点回调，不能被排队的画布缩放完成事件提前解除。面板退出回归使用真实 Qt 事件循环，检查多主题反复启动、主窗口销毁及 QApplication 强制回收。迁移后的快捷键另由画布、帮助目录、提示文案和文件列表回归覆盖。共享界面变化执行逐文件隔离的源码全量。

`tools/render_ui_scaling.py` 用隔离设置和生成图片分别控制 `--levels` 应用比例与 `--dpr` 系统显示比例，生成工作台、视图菜单、外观、首选项及类别选择器的 PNG 和 JSON。`--native` 使用 Windows Qt 平台插件打开真实窗口并记录 exposed 状态；offscreen 图库不能代替此项。单屏验证不能声称已完成真实混合 DPI 跨屏测试，原生系统对话框与窗口边框不纳入应用比例截图覆盖。
