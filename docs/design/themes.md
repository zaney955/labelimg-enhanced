# 外观与主题接口

“设置 → 外观…”在同一窗口提供颜色模式及强调色，选择后即时应用。窗口仅保留分段模式控制与具名圆形色板，不包含预览区。保存会同时持久化两项；取消、Escape 或关闭窗口恢复打开前的选择，不写入未保存的选择。原有用户默认保持浅色紫灰。

## 模式与强调色

颜色模式为跟随系统、浅色、深色。跟随系统在 Windows 读取应用颜色模式，每两秒检查变化，保留当前强调色；手动模式不受系统切换影响。不修改操作系统设置。其他平台通过原生 Qt 调色板通知更新。

预设紫灰、蓝色、青绿、绿色、琥珀、橙色、玫红、石板灰。强调色与模式独立保存为 `interface/colorMode` 和 `interface/accentColor`。深色模式自动提亮强调色，生成适合深色背景的悬停、选中和边框颜色；浅色模式按需压暗以保证可读性。正文、辅助文字、禁用文字和按钮文字的关键组合对比度至少 4.5:1，控件轮廓和图标至少 3:1。

原生文件选择器和操作系统窗口边框沿用平台外观。图像像素、类别配色和反色绘制辅助线保持数据语义；裁剪、框选、复核背景及放大镜外框/底栏使用界面主题。

## 添加强调色

`labelimg.ui.theme_palettes` 定义不可变的强调色预设与颜色计算，`labelimg.ui.theme` 是界面颜色的统一入口。新增预设只需注册中英文名称和基准色，外观窗口自动排列，浅色/深色语义调色板自动生成：

```python
from labelimg.ui.theme_palettes import AccentPreset, register_accent

register_accent(AccentPreset("ocean", "Ocean", "海蓝", "#306A87"))
```

在创建外观控制器前注册。重复 ID、空名称和非六位 RGB 色值被拒绝。自定义预设也应运行对比度及渲染验证。

`appearance_theme("dark", "ocean")` 返回完整主题；`AppearanceController.apply_preferences("system", "ocean", persist=True)` 更新并保存用户选择。产品入口通过控制器保持设置和界面一致，不直接调用底层切换。

完整主题由不可变的 `Theme` 定义，包含稳定 ID、中英文名称和完整的语义颜色表。`register_theme`、`available_themes`、`current_theme` 和 `set_theme` 提供底层注册/切换接口；缺失、未知颜色角色、非法色值和重复 ID 会被拒绝。`set_theme` 仅修改展示，不写设置文件，不改变图像、标注、类别颜色、选中状态或撤销历史。

## 组件接入

- 自绘界面在绘制时读取 `COLORS["accent"]` 等语义角色，不缓存旧 QColor。
- QSS 使用 `theme_style("QFrame { background: ${surface}; }")`，通过 `apply_theme_style(widget, style)` 绑定。禁止在组件中直接调用 `setStyleSheet` 或写死界面色值。
- 组合样式保留 `ThemeStyle` 模板；读取已有样式使用 `widget_theme_style(widget)`。
- 独立浮层调用 `present_surface`；任务对话框调用 `present_dialog`；工作台启动时安装应用调色板和控件样式，覆盖临时输入及进度窗口。
- 手工存储前景色的数据视图监听 `theme_changed`，仅刷新展示颜色。

切换在 Qt GUI 线程执行，先清除继承样式缓存，再绑定所有窗口的模板和调色板，覆盖首次显示前已创建的控件。命令及 QSS 控件内的 SVG 共用主题转换和缓存；命令图标交给 Qt 原生 SVG 图标引擎；切换时重新绑定命令图标，应用标识保持品牌图案。

语义角色包括表面/背景、正文/辅助文字、边框/分隔、强调/悬停/强调色上的文字、选中、禁用、危险/警告、预览中性底色、画布复核底色及功能图标。警告和错误保留独立含义。

## 验证

`test_appearance.py` 验证全部 16 种模式/强调色组合的对比度、系统跟随、手动隔离、保存/重启、取消回滚、中英文切换、深色首次启动及进程退出。`test_theme.py` 验证接口、已有及新建窗口、原生输入/进度控件、勾选状态、图标、图像和标注数据/历史不变，并阻止硬编码 QSS。`test_magnifier.py` 验证放大镜采样像素、双语、DPR 和安全放置。

`tools/render_ui_gallery.py --mode dark --accent teal` 渲染实际 Qt 界面；支持中英文及 100%/125%/150% 缩放。完整图库覆盖 57 个界面状态；`--focus` 保留工作台、调色板、几何变换、放大镜、裁剪、勾选状态、外观和系统跟随及更新流程的 11 个关键状态。清单记录模式、实际模式、强调色、主题 ID、DPR 和布局检查结果。系统跟随截图由注入的系统探针分别模拟浅色及深色，不更改本机系统主题。
