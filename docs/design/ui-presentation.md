# 全局界面外观

新增或修改界面先遵循 [UI 设计规范](ui-guidelines.md)。本文记录共享组件的具体呈现、尺寸及现有功能接入，通用设计与验收要求在规范中统一维护。

应用自有窗口以类别选择器、右侧标注区和文件筛选面板的界面层级为共同基准。单图标注工作台、菜单职责、命令位置、快捷键及事务语义由各功能设计继续定义；外观层不创建功能状态，也不修改标注颜色或图像内容。

## 外观与组件

应用自有界面支持独立的 75%～200% [全局界面缩放](ui-scaling.md)。本文尺寸均指 100% 基线，系统 DPI 由 Qt 独立处理。停靠面板内容及对话框可在空间不足时滚动，底部操作留在滚动区域外。

颜色角色和运行时切换由[主题接口](themes.md)统一定义，`labelimg.ui.presentation` 集中维护语义表面、背景、细边框、强调色和控件状态，支持浅色/深色及系统跟随。窗口内容边距为 18/16/18/14，分区边距为 12/10/12/12，常规间隔为 8–12 个逻辑像素。标题、分区标题、说明和统计摘要使用明确的语义角色。输入框、下拉框、数值框、滑块、表格、列表、页签和按钮共享同一组规则；图标沿用[矢量图标系统](../icon-design-system.md)。

对话框采用标题、内容及底部操作区。主操作使用强调色，次操作使用表面底色和边框，禁用状态仍由功能逻辑控制。复杂内容在屏幕空间不足时滚动，底部确认/取消及该功能实际提供的历史操作留在滚动区域外。显示时按当前屏幕可用区域限制窗口尺寸。原生文件选择器和操作系统窗口边框沿用平台外观。

任务标题使用对应矢量图标和紧凑标题，内容区用背景底与表面分区区分层级，避免依赖不同字号堆叠信息。下拉菜单按钮的箭头与文字水平对齐，统一由 SVG 绘制。

主工作台的标注、文件及质量结果面板共享语义表面、图标标题、紧凑计数和上下文操作区。绘制默认类别、标注目录及实际保存路径分别归入面板顶部的上下文区，查询输入位于列表上方；列表当前项沿用统一选择角色。标注实例的类别描边、选中填充、隐藏和悬停语义保持不变。基础控件和面板样式在停靠根绑定，标题及内容容器继承同一套规则并分别设置文字调色板，不复制整套样式；自绘计数/路径标签按控件外观绘制背景。

表格使用背景色表头、交替行背景和中间省略。未保存与外部冲突表格为路径列保留剩余空间，完整路径可通过提示查看；原始文本、数据角色、选择状态及解决方式不变。

## 覆盖范围

布局随任务重新组织：

- 批量重命名、类别替换采用左侧规则与右侧结果预览，预览按钮属于结果区，提交状态紧邻底部主操作。
- 几何变换与像素调整采用左侧大预览、右侧参数和目标列表；彩色边框修复移除单一工具的占位导航，将检测结果和目标图像放入侧栏页签。
- 标注统计使用图像、类别、标注框三个独立数值卡，筛选只改变结果显示。清理窗口将路径、扫描及候选选择集中在结果上方，并提供明确空状态。
- 调色板与快捷键帮助提供就地搜索。关于和更新中心直接展示身份/版本或任务状态，避免重复标题。
- 关于页使用应用标识、版本徽标、运行环境及项目主页入口；空工作台提供同一“打开图像目录”命令的起始入口，打开图像后自动让出画布。

页面正文只保留操作所需的信息，完整路径及次要规则通过提示查看。会保存标注并重置撤销历史的类别替换、负样本与回收站等影响决策的说明始终可见。

- 工作台菜单、顶部命令、左侧 Canvas 工具、底部状态及缩放控件。

- 标注外观、近重复框弹层、类别颜色、批量类别替换及标注统计。
- 文件批量重命名、标注文件清理、未保存编辑、外部标注冲突和恢复窗口。
- 图像几何变换、像素调整、彩色边框修复、质量检查设置及结果、显示调整和处理恢复。
- 快捷键帮助、关于和更新中心。

工作台底部统一为一条横跨窗口的三段式状态栏：左侧为原图坐标和标注尺寸，中间为弹性提示与目录加载操作，右侧依次为放大镜和画布缩放。普通消息可省略并提供完整悬停说明，重要失败提供完整详情入口；提示和加载按钮的出现不移动缩放滑块。窄窗口先压缩提示和滑块，必要时只将两组读数上下排列。具体优先级与响应规则见 [统一工作台状态栏](canvas-tool-rail.md#unified-workbench-status)。

底栏操作说明随实际指针目标和工具状态同步更新；普通结果在下一次交互时立即让位，不等待五秒计时结束。画框、平移、Ctrl 多选、拖动和裁剪各显示当前阶段说明。离开画布、切换图片及隐藏/删除目标后清理旧类别提示；切换语言重新投影当前说明，重要错误保留完整诊断并更新应用文案。计时器不得恢复已失效的悬停文案。

统计图、Canvas、图像预览和类别色块保留其数据表达，不能用界面强调色覆盖。颜色选择默认使用常用色板、当前色、十六进制输入和恢复默认入口；“更多颜色”打开完整 QColorDialog，保留取屏幕颜色及原生调色功能，内置文案随简体中文/英文切换。无效颜色禁止确认；取消不提交。会话类别颜色管理使用“应用”，保留会话范围提示。

字体尺寸集中在 `ui/typography.py`：正文 13、辅助信息 12、分区/面板标题 13、窗口标题 16、产品名 20、关键数字 24 个逻辑像素。`theme_style` 同时解析字体与颜色令牌。输入和列表保留必要边界；说明与分区使用轻表面和留白，避免边框层层嵌套。候选类别恢复彩色胶囊：8 像素类别色条、同色细边框、48/255 浅色填充，悬停和选中加粗边框；不使用纯色填满，也不改变类别颜色映射。

菜单复用 `ui.menu.Menu`，将勾选标记与操作图标分列；仍由 QMenu/QAction 负责键盘导航、触发、快捷键及子菜单。下拉列表选项高度至少 32 像素，随字体增大，文字左右留白；可编辑下拉框也接入同一委托。偏好设置的动作按钮按内容宽度排列并自动换行，搜索隐藏后重新排布；颜色设置的高级入口也按内容宽度呈现。

列表、表格、页签与选项使用同一主题选中底色。页签用底部强调线明确当前页，外观模式用对勾明确实际选择，键盘焦点使用虚线框，不复制选中底色。帮助菜单只保留快捷键、更新与关于，移除在线教程。

`present_dialog` 按完成后的布局计算初始尺寸，复杂内容才在可用屏幕内滚动，底栏固定。简单列表由列表自身滚动。质量检查默认显示标准策略摘要，自定义参数按单列展开并重新计算尺寸；说明亮度范围与阈值方向，确认按钮为“开始检查”。未检查提供开始入口，全部通过保留数量，无法读取与整次检查失败分别表达。

设置菜单的“偏好设置”索引支持搜索，复用现有动作和状态。开关即时生效；子窗口使用原有保存、应用或取消契约。视图中的“恢复默认布局”仅恢复初始停靠布局；外观单独提供恢复默认及取消还原。重置全部设置先确认范围，再处理未保存编辑，只有关闭获准后才清空偏好并重启。取消任一步不会清空设置或启动新进程。

## 双语与验证

新增分区文案进入统一消息目录。长驻组件响应语言切换；临时窗口打开时使用当前语言。路径、用户类别、格式名及原始系统诊断保持原文，遵循[双语界面](bilingual-interface.md)。

测试模式及完整渲染命令统一见[开发指南](../development.md)。界面渲染使用真实 Qt 控件和临时图像/标注，不执行实际修改或联网更新。

对简体中文和英文分别验证 100%、125%、150% 缩放。工具模拟 1920×1080 桌面的可用逻辑区域，保留 Qt 实际的 DPR 渲染，检查窗口边界和底部操作区，输出 PNG 与 JSON 清单。它是可复现的无界面渲染检查，不替代真实操作系统窗口的人工验收。

Windows offscreen 插件直接显示 QMessageBox 会崩溃，最小原生控件也可复现。消息框因此使用真实隐藏控件绘制，清单标记为 `hidden-widget`；这项渲染不确认原生窗口的实际弹出行为。


## 工作台面板与分块

工作区使用独立的背景间隔，画布、标注、文件及质量面板有各自的细边框；面板之间保留 6 个逻辑像素的原生可拖动分隔区域，悬停使用强调色提示。左侧仍只保留 Canvas 工具，主画布优先。

所有停靠面板复用 `labelimg.ui.panels.PanelHeader`：38 像素标题栏、16 像素功能图标、标题与计数、26 像素操作按钮。标题栏完整提供 Qt 尺寸提示，避免自定义标题与内容重叠。上下文区采用相同内边距、输入高度和底部分隔线；列表占用剩余空间，选择操作固定在面板底部，去掉嵌套卡片边框。质量面板的刷新、清除结果与关闭位于标题栏，检查摘要留在上下文区。

标题栏保留原生拖动、双击浮动/停靠；右键位置菜单提供左、右、底部、顶部和浮动/停靠，使用当前语言且不增加全局快捷键。标注和文件面板维持原有关闭策略，质量面板可关闭。原有布局保存与恢复继续使用 Qt dock state，支持调整尺寸和标签页组合。列表区可缩小，三面板与选择操作同时显示时不强制窗口超过可用屏幕；筛选空态保留清除筛选入口。

`workspace_gutter`、`panel_header`、`panel_border` 通过统一主题接口提供，浅色、深色及各强调色共用组件，不在面板内写死颜色。`test_panel_chrome.py` 验证实际 Qt 几何、原生双击、位置菜单、宽度调整、布局恢复、紧凑屏幕、按钮状态和主题/语言切换。渲染工具 `--panels-only` 选择停靠、浮动、页签、紧凑窗口及选择操作等面板状态，覆盖范围以脚本及输出清单为准。


## 标签类别多选

标签列表与文件列表共用 `selection_background`、`selection_border` 和 `selection_foreground`。包含已选实例的类别使用相同的圆角整行底色和细边框；当前活动实例、鼠标悬停以及焦点移至底部操作均不弱化其它已选行。取消左侧选中竖条与圆点；整类选择使用实线边框和加粗类别名，部分选择使用虚线边框、普通字重及“已选数/总数”，实例编号继续表示具体选择，类别色标、描边和 48/255 填充保持不变。计数列按场景预留足够宽度，选择变化不移动实例和状态列；极窄视图保留完整实例入口并省略长计数，精确数量见原有提示。该呈现不改变 Canvas 标注颜色、命中、Ctrl/Shift 多选或隐藏标注语义。

`test_label_group_selection.py` 比对实际文件委托与标签列表的选中底色及边框，检查多类别、部分选择、Ctrl 手势、失焦、悬停、16 组模式/强调色，以及类别填充上的编号文字对比度。[标签渲染工具](../../tools/render_label_selection.py)用临时标注覆盖整类、部分、失焦与悬停状态，以及模式/强调色组合；具体输出见运行清单。
