# 全局界面外观

新增或修改界面先遵循 [UI 设计规范](ui-guidelines.md)。本文记录共享组件的具体呈现、尺寸及现有功能接入，通用设计与验收要求在规范中统一维护。

应用自有窗口以类别选择器、右侧标注区和文件筛选面板的界面层级为共同基准。单图标注工作台、菜单职责、命令位置、快捷键及事务语义由各功能设计继续定义；外观层不创建功能状态，也不修改标注颜色或图像内容。

## 外观与组件

颜色角色和运行时切换由[主题接口](themes.md)统一定义，`labelimg.ui.presentation` 集中维护语义表面、背景、细边框、强调色和控件状态，支持浅色/深色及系统跟随。窗口内容边距为 18/16/18/14，分区边距为 12/10/12/12，常规间隔为 8–12 个逻辑像素。标题、分区标题、说明和统计摘要使用明确的语义角色。输入框、下拉框、数值框、滑块、表格、列表、页签和按钮共享同一组规则；图标沿用[矢量图标系统](../icon-design-system.md)。

对话框采用标题、内容及底部操作区。主操作使用强调色，次操作使用表面底色和边框，禁用状态仍由功能逻辑控制。复杂内容在屏幕空间不足时滚动，底部确认/取消以及图像工具的撤销/重做留在滚动区域外。显示时按当前屏幕可用区域限制窗口尺寸。原生文件选择器和操作系统窗口边框沿用平台外观。

任务标题使用对应矢量图标和紧凑标题，内容区用背景底与表面分区区分层级，避免依赖不同字号堆叠信息。下拉菜单按钮的箭头与文字水平对齐，统一由 SVG 绘制。

主工作台的标注、文件及质量结果面板共享语义表面、图标标题、紧凑计数和上下文操作区。绘制默认类别、标注目录及实际保存路径分别归入面板顶部的上下文区，查询输入位于列表上方；列表当前项沿用统一选择角色。标注实例的类别描边、选中填充、隐藏和悬停语义保持不变。停靠窗口的标题及内容容器分别接入样式，自绘计数/路径标签按控件外观绘制背景并使用正确的文字调色板。

表格使用背景色表头、交替行背景和中间省略。未保存与外部冲突表格为路径列保留剩余空间，完整路径可通过提示查看；原始文本、数据角色、选择状态及解决方式不变。

## 覆盖范围

布局随任务重新组织：

- 批量重命名、类别替换采用左侧规则与右侧结果预览，预览按钮属于结果区，提交状态紧邻底部主操作。
- 几何变换与像素调整采用左侧大预览、右侧参数和目标列表；彩色边框修复移除单一工具的占位导航，将检测结果和目标图像放入侧栏页签。
- 标注统计使用图像、类别、标注框三个独立数值卡，筛选只改变结果显示。清理窗口将路径、扫描及候选选择集中在结果上方，并提供明确空状态。
- 调色板与快捷键帮助提供就地搜索。关于和更新中心直接展示身份/版本或任务状态，避免重复标题。
- 关于页使用应用标识、版本徽标、运行环境及项目主页入口；空工作台提供同一“打开图像目录”命令的起始入口，打开图像后自动让出画布。

页面正文只保留操作所需的信息，完整路径及次要规则通过提示查看。会保存标注并重置撤销历史的类别替换、负样本与回收站等影响决策的说明始终可见。

- 工作台菜单、顶部命令、左侧 Canvas 工具、底部状态及缩放控件。
- 标注外观、近重复框弹层、类别颜色、批量类别替换及标注统计。
- 文件批量重命名、标注文件清理、未保存编辑、外部标注冲突和恢复窗口。
- 图像几何变换、像素调整、彩色边框修复、质量检查设置及结果、显示调整和处理恢复。
- 快捷键帮助、关于和更新中心。

统计图、Canvas、图像预览和类别色块保留其数据表达，不能用界面强调色覆盖。QColorDialog 保留原有选色和恢复默认交互，其内置文案通过应用所有的 Qt 翻译器随简体中文/英文切换。

## 双语与验证

新增分区文案进入统一消息目录。长驻组件响应语言切换；临时窗口打开时使用当前语言。路径、用户类别、格式名及原始系统诊断保持原文，遵循[双语界面](bilingual-interface.md)。

运行 `python -B tools/run_tests.py`，逐文件在隔离进程中通过 unittest discovery 执行全部测试。`--installed` 验证当前环境的安装包；`--package-root <directory>` 验证独立目录中的 wheel 安装。测试配置由 `LABELIMG_CONFIG_DIR` 隔离。

界面渲染使用真实 Qt 控件和临时图像/标注，不执行实际修改或联网更新：

```powershell
$env:PYTHONPATH = "$PWD/src"
python -B tools/render_ui_gallery.py --output .test-state/ui-zh-150 --language zh_CN --scale 1.5
```

对简体中文和英文分别验证 100%、125%、150% 缩放。工具模拟 1920×1080 桌面的可用逻辑区域，保留 Qt 实际的 DPR 渲染，检查窗口边界和底部操作区，输出 PNG 与 JSON 清单。它是可复现的无界面渲染检查，不替代真实操作系统窗口的人工验收。

Windows offscreen 插件直接显示 QMessageBox 会崩溃，最小原生控件也可复现。消息框因此使用真实隐藏控件绘制，清单标记为 `hidden-widget`；这项渲染不确认原生窗口的实际弹出行为。


## 工作台面板与分块

工作区使用独立的背景间隔，画布、标注、文件及质量面板有各自的细边框；面板之间保留 6 个逻辑像素的原生可拖动分隔区域，悬停使用强调色提示。左侧仍只保留 Canvas 工具，主画布优先。

所有停靠面板复用 `labelimg.ui.panels.PanelHeader`：38 像素标题栏、16 像素功能图标、标题与计数、26 像素操作按钮。标题栏完整提供 Qt 尺寸提示，避免自定义标题与内容重叠。上下文区采用相同内边距、输入高度和底部分隔线；列表占用剩余空间，选择操作固定在面板底部，去掉嵌套卡片边框。质量面板的刷新、清除结果与关闭位于标题栏，检查摘要留在上下文区。

标题栏保留原生拖动、双击浮动/停靠；右键位置菜单提供左、右、底部、顶部和浮动/停靠，使用当前语言且不增加全局快捷键。标注和文件面板维持原有关闭策略，质量面板可关闭。原有布局保存与恢复继续使用 Qt dock state，支持调整尺寸和标签页组合。列表区可缩小，三面板与选择操作同时显示时不强制窗口超过可用屏幕；筛选空态保留清除筛选入口。

`workspace_gutter`、`panel_header`、`panel_border` 通过统一主题接口提供，浅色、深色及各强调色共用组件，不在面板内写死颜色。`test_panel_chrome.py` 验证实际 Qt 几何、原生双击、位置菜单、宽度调整、布局恢复、紧凑屏幕、按钮状态和主题/语言切换。渲染工具 `--panels-only` 覆盖 13 个面板状态；完整图库包含 67 个界面状态。


## 标签类别多选

标签列表与文件列表共用 `selection_background`、`selection_border` 和 `selection_foreground`。包含已选实例的类别使用相同的圆角整行底色和细边框；当前活动实例、鼠标悬停以及焦点移至底部操作均不弱化其它已选行。取消左侧选中竖条与圆点；整类选择使用实线边框和加粗类别名，部分选择使用虚线边框、普通字重及“已选数/总数”，实例编号继续表示具体选择，类别色标、描边和 48/255 填充保持不变。计数列按场景预留足够宽度，选择变化不移动实例和状态列；极窄视图保留完整实例入口并省略长计数，精确数量见原有提示。该呈现不改变 Canvas 标注颜色、命中、Ctrl/Shift 多选或隐藏标注语义。

`test_label_group_selection.py` 比对实际文件委托与标签列表的选中底色及边框，检查多类别、部分选择、Ctrl 手势、失焦、悬停、16 组模式/强调色，以及类别填充上的编号文字对比度。`tools/render_label_selection.py --output .test-state/labels --language zh_CN --scale 1.5` 用临时标注渲染整类、部分、失焦与悬停四种状态；每种语言和缩放产生 64 张面板图及浅深色工作台图。
